问题与价值

管理知识库，不该全靠手动

笔记多了以后，知识孤岛、标签混乱、周度回顾负担——这些痛点，KiloCode 帮你解决。

之前：全靠手动

  • 笔记写了就放着，很少再整理
  • 标签体系慢慢走形
  • 周度回顾需要自己做、自己记
  • 知识孤岛没人管
  • 知识沉淀全靠手动整理

之后：AI 帮你管

  • 知识处理技能随时可用（vault 中的 markdown 文件）
  • 之前的会话可搜索、可复用
  • 每周回顾一键执行
  • AI 自动发现知识孤岛和标签混乱
  • 知识随着时间不断积累和梳理

核心特性

一个插件，打通知识管理与 AI 工具

从聊天到技能系统，从文件引用到 MCP 工具，KiloCode 让 AI 真正了解你的知识库。

💬

AI 聊天侧边栏

在 Obsidian 侧边栏与 KiloCode AI 对话，每条消息自动携带 vault 路径和当前笔记作为上下文。

@

@ 提及 Vault 文件

输入 @ 搜索并引用任意 vault 文件、文件夹或 MCP 服务器，笔记内容无缝流入对话。

#

自定义指令

点击 # 编写自定义系统提示词，注入当前对话。自动保存，每个 session 重新应用。

📎

文件附件

拖拽、粘贴或点击附加文件。文本文件自动读取内容发送给 AI 对话。

📝

当前笔记上下文

一键切换将活跃笔记作为 AI 上下文。插件通过 Vault API 读取并传递给 CLI。

⚡

Vault 内技能系统

技能是 .kilo/skills/ 下的 .md 文件。写一个 weekly-review 流程 → 一键执行。编辑即生效，无需重启。

⚙️

斜杠命令

/skill、/model、/mode、/compact、/clear — 五个命令覆盖日常所有操作。

🔌

MCP 工具框架

.kilocode/mcp.json 定义 AI 工具。插件在 @mention 下拉列出可用 MCP 服务器。

🎭

三种模式

Code（完整读写）、Plan（只读分析）、Ask（仅问答）。模式前缀注入每条消息。

📑

多标签页聊天

多个独立聊天会话。每个标签页的对话历史存储在 .kilocode/sessions/ 中，跟随 vault 备份。

🔄

流式响应

实时 AI 响应，支持取消中断。插件消费 CLI 异步生成器，增量更新 UI。

🍴

分支与回退

在任意消息处创建分支（Fork），或回退到之前的对话状态。不满意就重来。

🔒

权限系统

Yolo（自动放行）/ Normal（逐次审批）/ Plan（只读保障）。工具调用到达 CLI 前进行拦截。

🌍

国际化

中英文界面，支持根据浏览器语言自动切换。贡献者轻松添加新语言。

🚀

零配置启动

首次使用自动下载 CLI 二进制。已安装 kilo？自动检测并使用现有配置。API 密钥、模型偏好全部继承。

安装与快速参考

三步开始，一个命令上手

零配置启动，无需手动安装 CLI。三种安装方式覆盖所有场景。

安装方式

🏆 推荐：社区插件

  1. 打开 Obsidian → 设置 → 社区插件 → 浏览
  2. 搜索 "KiloCode" 并点击安装
  3. 启用插件

📦 GitHub Release

  1. 从最新 Release 下载 main.js、manifest.json、styles.css
  2. 放入 <vault>/.obsidian/plugins/kilocode/

🔧 从源码构建

  1. git clone 到 .obsidian/plugins/
  2. npm install && npm run build

快速参考

@ 提及文件 输入 @ 或点击工具栏
斜杠命令 输入 / 或点击工具栏
自定义指令 点击工具栏 #
文件附件 点击工具栏 📎
笔记上下文 切换工具栏 📝
切换模式 点击模式按钮 或 Shift+Tab
分支 / 回退 悬停消息显示操作按钮
内联编辑 选中文本 → Ctrl+Shift+E
