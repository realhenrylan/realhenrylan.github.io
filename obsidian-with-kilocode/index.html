我的知识库，用AI 来管

v0.8.0 Obsidian v1.7.2+ MIT 社区插件已上架

我有一个知识库（Obsidian），我有一个 AI 工具（KiloCode）。这个插件让它们在一起工作。笔记、技能、会话历史，全部在 vault 里，用同一个 KiloCode 来管理。

01 — 问题与价值

管理知识库，不该全靠手动

笔记多了以后，知识孤岛、标签混乱、周度回顾负担——这些痛点，KiloCode 帮你解决。

✕ 之前

  • 笔记写了就放着，很少再整理
  • 标签体系慢慢走形
  • 周度回顾需要自己做、自己记
  • 知识孤岛没人管
  • 知识沉淀全靠手动整理

✓ 之后

  • 知识处理技能随时可用（vault 中的 markdown 文件）
  • 之前的会话可搜索、可复用
  • 每周回顾一键执行
  • AI 自动发现知识孤岛和标签混乱
  • 知识随着时间不断积累和梳理

03 — 核心特性

一个插件，打通知识管理与 AI 工具

从聊天到技能系统，从文件引用到 MCP 工具——KiloCode 让 AI 真正了解你的知识库。

chat 💬

AI 聊天侧边栏

在 Obsidian 侧边栏与 KiloCode AI 对话，每条消息自动携带 vault 路径和当前笔记作为上下文。

input @

@ 提及 Vault 文件

输入 @ 搜索并引用任意 vault 文件、文件夹或 MCP 服务器，笔记内容无缝流入对话。

input #

自定义指令

点击 # 编写自定义系统提示词，注入当前对话。自动保存，每个 session 重新应用。

input 📎

文件附件

拖拽、粘贴或点击附加文件。文本文件自动读取内容发送给 AI 对话。

context 📝

当前笔记上下文

一键切换将活跃笔记作为 AI 上下文。插件通过 Vault API 读取并传递给 CLI。

skills ⚡

Vault 内技能系统

技能是 .kilo/skills/ 下的 .md 文件。写一个 weekly-review 流程 → 一键执行。编辑即生效，无需重启。

commands ⚙

斜杠命令

/skill、/model、/mode、/compact、/clear — 五个命令覆盖日常所有操作。

tools MCP

MCP 工具框架

.kilocode/mcp.json 定义 AI 工具。插件在 @mention 下拉列出可用 MCP 服务器。

mode ▶

三种模式

Code（完整读写）、Plan（只读分析）、Ask（仅问答）。模式前缀注入每条消息。

chat ⇥

多标签页聊天

多个独立聊天会话。对话历史存储在 .kilocode/sessions/ 中，跟随 vault 备份。

stream ⟳

流式响应

实时 AI 响应，支持取消中断。消费 CLI 异步生成器，增量更新 UI。

history ⑂

分支与回退

在任意消息处创建分支，或回退到之前的对话状态。不满意就重来。

security ◉

权限系统

Yolo / Normal / Plan。工具调用到达 CLI 前进行拦截，数据安全第一。

i18n ⇄

国际化

中英文界面，支持根据浏览器语言自动切换。贡献者轻松添加新语言。

cli ⟶

零配置启动

首次使用自动下载 CLI 二进制。已安装 kilo？自动继承 API 密钥和模型配置。

config ⚙

CLI 配置同步

直接读取 ~/.config/kilo/kilo.jsonc。API 密钥、模型选择、代理设置全部继承。

05 — 安装与快速参考

三种方式，零配置启动

无需手动安装 CLI——插件首次使用自动下载。三种安装方式覆盖所有场景。

❯ 安装

社区插件 推荐
  1. 打开 Obsidian → 设置 → 社区插件 → 浏览
  2. 搜索 "KiloCode" 并点击安装
  3. 启用插件
GitHub Release pkg
  1. 下载 main.js、manifest.json、styles.css
  2. 放入 .obsidian/plugins/kilocode/
从源码 dev
  1. git clone 到 .obsidian/plugins/
  2. npm install && npm run build

⌨ 快速参考

  • @ 提及文件 输入 @ 或工具栏
  • 斜杠命令 输入 / 或工具栏
  • 自定义指令 点击工具栏 #
  • 文件附件 点击工具栏 📎
  • 笔记上下文 切换工具栏 📝
  • 切换模式 点击或 Shift+Tab
  • 分支 / 回退 悬停消息
  • 内联编辑 选中 → Ctrl+Shift+E
