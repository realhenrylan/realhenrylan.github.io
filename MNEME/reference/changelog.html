Engineering · Changelog

Changelog

A concise record of product-facing changes, engineering improvements, and the boundaries Mneme is designed to keep visible.

View the full CHANGELOG.md on GitHub ↗

Unreleased2026-07-27

Website redesign: local memory you can verify

The public site now explains Mneme through a single path: local files → inspectable index → connected retrieval → source-linked answers.

Added

  • New English and Simplified Chinese landing pages.
  • Evidence demo with expandable source chips.
  • Platform-aware install commands with copy feedback.
  • Real TUI screenshot from the local workflow.

Changed

  • Reframed the hero around local-first, evidence-backed memory.
  • Grouped capabilities into retrieval, relationships, and control.
  • Raised supporting type sizes for easier reading.
  • Redesigned the light/dark theme glyph as an orbiting sun/moon mark.

Fixed

  • Removed emoji-only feature signaling from the homepage.
  • Reduced mobile whitespace around the primary proof.
  • Kept legacy documentation URLs reachable.
  • Removed the visible keyboard hint from the search control.

Security

  • Documented exactly what stays local.
  • Clarified when retrieved snippets can reach a configured LLM endpoint.
  • No claim is made that exceeds the configured boundary.
UnreleasedProduct baseline

Runtime and developer experience

  • Embedding model auto-download: falls back to ModelScope for all-MiniLM-L6-v2 when the local cache is unavailable.
  • CLI loop refactor: shared interactive session logic is extracted from rag.py and graph_rag.py.
  • Import cleanup: removes sys.path hacks and circular imports and adds editable-install metadata.
  • LLM client singleton: lazy initialization reduces repeated client construction.
1.1.02026-07-04

Onboarding and provider setup

  • Added a first-launch setup wizard for API key, provider, base URL, and model selection.
  • Linked DeepSeek, OpenAI, and custom provider presets to available model lists.
1.0.32026-07-04

Source display fixes

  • Fixed error states incorrectly displaying Sources alongside error messages.
1.0.22026-07-04

Configuration persistence

  • Fixed Temperature, Alpha, and Top-K Min/Max settings being lost after restart.
1.0.12026-07-03

Graph RAG batch safety

  • Fixed thread-unsafe _entity_cache writes and incorrect per-chunk API calls in Graph RAG batch processing.
1.0.02026-07-03

Initial release

  • Introduced the TUI, hybrid retrieval, Graph RAG, query decomposition, and the initial test suite.
