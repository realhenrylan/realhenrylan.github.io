2026-07

Website and product surface

Added

  • New Anthropic-inspired Mneme design system with paper canvas, graphite text, memory purple, and evidence green.
  • Real TUI screenshot as the homepage’s primary proof asset.
  • Dedicated pages for retrieval, Graph RAG, query decomposition, safety, guides, references, and engineering notes.

Changed

  • Rebuilt the static site from a shared semantic HTML shell instead of the old VitePress output.
  • Unified English and Simplified Chinese navigation, typography, code blocks, search, theme switching, and footer.
  • Moved data-boundary language into the homepage and feature documentation.

Fixed

  • Removed the duplicate old visual system that appeared after clicking top navigation.
  • Removed old hashed VitePress assets and generated pages from the published surface.

2026-06

Mneme’s retrieval and TUI work continued around hybrid retrieval, Graph RAG, source citations, and bounded context handling.
