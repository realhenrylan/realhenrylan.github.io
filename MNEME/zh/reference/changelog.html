未发布2026-07-27

网站重设计：一套可验证的本地记忆

新首页用一条清晰路径解释 Mneme：本地文件 → 可检查的索引 → 关系扩展检索 → 带来源的回答。

新增

  • 新增英文与简体中文落地页。
  • 新增可展开来源的证据演示。
  • 新增带复制反馈的平台安装命令。

变更

  • Hero 改为围绕本地优先、证据可查的记忆来叙事。
  • 将能力聚合为检索、关系和自主控制三类。
  • 加入响应式导航、搜索和主题切换。

修复

  • 移除首页仅用 emoji 表示功能的方式。
  • 减少移动端首屏证明区域的空白。
  • 保留旧文档 URL 的可访问性。

安全

  • 明确说明哪些内容始终留在本地。
  • 说明检索片段何时会到达已配置的 LLM 端点。
  • 不做超出真实边界的安全承诺。
未发布产品基线

运行时与开发体验

  • Embedding 模型自动下载：本地缓存不可用时回退到 ModelScope 下载 all-MiniLM-L6-v2。
  • CLI 循环重构：将 rag.py 和 graph_rag.py 的共享交互会话逻辑提取出来。
  • 导入清理：移除 sys.path hack 和循环导入，添加可编辑安装元数据。
  • LLM 客户端单例：使用惰性初始化，减少重复创建客户端。
