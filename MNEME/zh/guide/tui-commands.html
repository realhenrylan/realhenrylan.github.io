命令参考

命令作用
/help显示全部命令。
/files添加、移除、列出、监视或停止监视文件。
/mode切换 Standard RAG 与 Graph RAG。
/alpha设置 Graph RAG 融合权重。
/settings查看或修改 API 设置。
/status显示索引和服务状态。
/quit退出 TUI。

监视目录

/files watch /path/to/directory\n/files list\n/files stop

变化会去抖并串行处理，保持本地索引同步。

选择检索模式

Standard RAG 适合通用问题；Graph RAG 在问题依赖跨文档关系时增加实体关系扩展。

检查回答

无论哪种模式，都可以通过回答中的来源标记打开原文件、页码或片段。
