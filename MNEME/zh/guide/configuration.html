最小连接配置

Mneme 使用 OpenAI-compatible 端点完成 LLM 能力。把这些值写入 .env，也可以由 onboarding wizard 保存。

API_KEY=sk-your-api-key-here\nBASE_URL=https://api.deepseek.com/v1\nLLM_MODEL=deepseek-chat
端点边界

远程端点默认必须使用 HTTPS。回环地址允许 HTTP；非本地 HTTP 需要 MNEME_ALLOW_INSECURE_HTTP=1。

检索与生成

变量默认值用途
LLM_TEMPERATURE0.2生成温度。
LLM_TOP_K_MIN12标准检索最小片段数。
LLM_TOP_K_MAX70标准检索最大片段数。
ALPHA0.7Graph RAG 融合权重。

资源限制

变量默认值用途
MNEME_MAX_DOCUMENT_BYTES52428800最大文档大小：50 MiB。
MNEME_MAX_PDF_PAGES2000单个 PDF 最大页数。
MNEME_MAX_REMOTE_CONTEXT_CHARS60000发送给 LLM 端点的最大检索上下文。

什么会离开本机

文件发现、解析、索引、缓存管理和向量/BM25 检索都在本地完成。使用 LLM 能力时，检索片段会发送到你配置的端点，用于生成回答、查询拆解或 Graph RAG 实体提取。
