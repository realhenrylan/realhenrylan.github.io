它如何工作

从散落的文件，到可检查的记忆。

Mneme 让过程保持清晰：从已有文档开始，再沿着问题、回答和背后的证据一路回查。

01

加入文件

指向一个包含笔记、报告、代码或导出的文件夹。

/files add ./docs
02

建立记忆

index fingerprint: 8c3f…
03

跨文档提问

在同一个问题里寻找语义、精确术语和关联上下文。

/mode graph
04

检查证据

在相信结论前，打开它引用的文件、页码或片段。

内部机制服务于三个清晰结果：找到正确片段，沿着关系追踪上下文，并始终掌握数据边界。

数据边界

“本地优先”不是口号，而是一条边界。

下面是精确的划分。本地工作流可以独立使用；LLM 能力只增加一次明确、可配置的数据交接。

始终在本地
  • 文件发现与解析
  • 索引与缓存管理
  • 向量和 BM25 检索
使用时发送至你配置的端点
  • 用于生成回答的检索片段
  • 用于查询拆解的检索片段
  • 用于 Graph RAG 实体提取的检索片段

Mneme 不替你选择端点。默认值与限制请见安全设计文档 ↗。

开发者起步

安装 Python 包；只有在需要 LLM 能力时配置端点；然后启动终端 UI。

git clone https://github.com/realhenrylan/mneme.git
cd mneme
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m tui
