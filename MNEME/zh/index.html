Mneme本地文档 RAG 与 Graph RAG

以 Mnemosyne——希腊神话中的记忆女神——命名，一个带有终端 UI 的本地文档检索增强生成系统。

快速开始
GitHub
🔍

混合检索

Sentence-transformers + ChromaDB 语义搜索与 BM25 关键词搜索通过 RRF（倒数排名融合）结合，兼顾语义和词法两个世界。

🕸️

Graph RAG

LLM 提取的实体关系扩展检索，支持跨文档关联问题。共现阈值保持图谱清洁。

🧩

查询拆解

复杂问题被拆分为子查询并发检索，然后融合为单一综合回答。

🛡️

安全设计

默认 HTTPS 端点、有界文档大小、显式不可信文档边界和 Schema 验证的 JSON 缓存。

💻

终端 UI

基于 Rich 的双语 TUI，支持流式聊天、斜杠命令、文件管理、设置和防抖目录监听。

📄

广泛格式支持

PDF、DOCX、Markdown、HTML、JSON、CSV、源代码和配置文件。本地索引，可验证引用查询。

快速预览 ​

bash
# 克隆并安装
git clone https://github.com/realhenrylan/mneme.git
cd mneme
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows
# source .venv/bin/activate  # macOS / Linux
python -m pip install -e ".[dev]"

# 配置
copy .env.example .env
# 编辑 .env 填入你的 API_KEY 和 BASE_URL

# 启动 TUI
python -m tui
