关于 Mneme

Mneme 以记忆女神 Mnemosyne 命名，面向希望获得有用回答、同时保留文件证据路径的开发者。

核心主张

Mneme 把文档当作一套应该可以检查的记忆。它索引本地文件、跨文档检索，并只在你选择使用 LLM 能力时调用 OpenAI-compatible 端点。

你的文档，一套可验证的记忆。

仓库内容

表面用途
src/Standard RAG、Graph RAG、查询拆解、引用、队列、指标、质量和安全。
tui/流式对话、斜杠命令、设置、文件管理和目录监视。
tests/离线安全的单元、集成和回归测试。
benchmarks/检索质量数据和评估表面。

界面应该让什么可见

  • 文件、解析、索引和检索都由本地拥有。
  • 带来源的回答，以及足够打开检查的定位信息。
  • 使用 LLM 能力时，端点和上下文的明确边界。
  • 从 CLI 或终端 UI 开始，而不是云端控制台。
