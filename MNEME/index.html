MnemeLocal-document RAG with Graph RAG

Named after Mnemosyne, the Greek goddess of memory — a local-document Retrieval-Augmented Generation system with a terminal UI.

Get Started
View on GitHub
🔍

Hybrid Retrieval

Sentence-transformers + ChromaDB semantic search fused with BM25 keyword search using RRF (Reciprocal Rank Fusion). Best of both semantic and lexical worlds.

🕸️

Graph RAG

LLM-extracted entity relationships expand retrieval for connected, cross-document questions. Co-occurrence thresholds keep the graph clean.

🧩

Query Decomposition

Complex questions are split into sub-queries and retrieved concurrently, then fused into a single comprehensive answer.

🛡️

Safety by Design

HTTPS-by-default endpoints, bounded document sizes, explicit untrusted-document boundaries, and schema-validated JSON caches.

💻

Terminal UI

Rich-based bilingual TUI with streaming chat, slash commands, file management, settings, and debounced directory watching.

📄

Wide Format Support

PDF, DOCX, Markdown, HTML, JSON, CSV, source code, and configuration files. Index locally, query with verifiable citations.

Quick Preview ​

bash
# Clone and install
git clone https://github.com/realhenrylan/mneme.git
cd mneme
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows
# source .venv/bin/activate  # macOS / Linux
python -m pip install -e ".[dev]"

# Configure
copy .env.example .env
# Edit .env with your API_KEY and BASE_URL

# Launch the TUI
python -m tui
